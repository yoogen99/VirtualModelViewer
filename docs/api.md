# 共通モデルAPI v0.1

ビューアとAPIは同じHTTPSオリジンに配置します。寸法はすべてメートルです。Blender・Fusionアドオンはこの共通APIを利用しています。

| 操作 | メソッド・パス | 認証 |
| --- | --- | --- |
| 新規発行 | `POST /api/models` | `Authorization: Bearer <UPLOAD_TOKEN>` |
| 同じURLで更新 | `PUT /api/models/:id` | 同上 |
| 削除 | `DELETE /api/models/:id` | 同上 |
| 閲覧情報 | `GET /api/models/:id` | URL内の推測困難なID |
| GLB取得 | `GET /api/models/:id/asset.glb?v=:revision` | 同上 |
| QRコードPNG | `GET /api/models/:id/qr.png` | 同上 |

## 送信

POST・PUTは`multipart/form-data`で次の2フィールドを送ります。

- `model`：GLB 2.0ファイル（最大25MiB）。バイナリ・画像を内包する形式。
- `metadata`：次のJSON文字列。名前は1〜120文字、各寸法は0〜10,000mの有限数、少なくとも1軸は0より大きい値。

```json
{
  "name": "基準キューブ",
  "dimensions": { "width": 1, "height": 1, "depth": 1 }
}
```

glTF座標は右手系・Y上方向、原点はモデル全体の底面中央としてください。アドオン側で評価後の形状とワールド変換を適用し、寸法とGLBの実際の大きさを一致させます。APIはGLBコンテナと埋め込みリソースの構造を確認しますが、完全なglTF検証やジオメトリからの寸法再計算は行いません。圧縮拡張は初期版の対象外です。

## 応答

新規発行は201、更新・閲覧情報は200で同じ形式を返します。

```json
{
  "id": "<48桁のランダムな16進数>",
  "name": "基準キューブ",
  "dimensions": { "width": 1, "height": 1, "depth": 1 },
  "revision": "<UUID>",
  "expiresAt": "2026-10-20T00:00:00.000Z",
  "viewerUrl": "https://viewer.example/v/<id>",
  "assetUrl": "https://viewer.example/api/models/<id>/asset.glb?v=<revision>"
}
```

更新の完了時に最新の版へ切り替え、有効期限を24時間延長します。競合する更新は片方を409で拒否し、削除後に進行中の更新から復活させることはありません。旧版を指定した取得は404になります。更新・削除は管理用トークンを持つすべての利用者が実行できます。

削除成功は204です。期限切れ・削除後・存在しないIDは、情報とファイルの取得で404を返します。期限切れリンクの更新も404となるため、新規発行してください。削除は繰り返し実行できます。

## エラーとキャッシュ

エラーは`{"error":"日本語メッセージ"}`です。400＝入力不正、401＝認証失敗、404＝無効リンク／旧版、405＝未対応操作、409＝更新競合、413＝サイズ超過、415＝送信形式不正、500＝配信処理失敗、503＝サーバーのトークン未設定です。

モデル関連レスポンスは`Cache-Control: no-store`で配信します。期限切れでも、すでに保存されたデータや開いているネイティブAR画面を遠隔消去することはできません。
